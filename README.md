# Jay Dhandhukiya — React Portfolio

A clean, responsive, one-page frontend developer portfolio built with React + JavaScript + CSS.

## Stack

- React 19
- JavaScript
- Vite
- Lucide React
- Plain CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Easy customization

Most portfolio content is intentionally kept in `src/main.jsx`:

- `profile` → name, email, phone, LinkedIn and summary
- `skills` → skill groups
- `experiences` → work history
- `projects` → project cards and links

Design/layout is in `src/styles.css`.

## Notes

The portfolio content is based on the supplied resume. Replace or remove any project URL if it is no longer publicly accessible.
